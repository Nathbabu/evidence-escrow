Public interface

Method Caller Purpose
__init__(payee, terms) deployer Deploys the deal. The deployer becomes the payer.
fund() payer Deposits the escrowed amount, payable, callable once.
confirm_complete() payer Releases the full balance to the payee. No dispute, no AI.
cancel_deal() payer Calls off the deal, full refund if funded. Blocked once the payee has submitted evidence.
submit_evidence(evidence, evidence_url) payer/payee Records your side. First call opens the dispute and starts the 24-hour response window.
resolve_dispute() payer/payee Triggers the AI-arbitrated ruling, once both sides responded or the window passed.
get_terms / get_status / get_parties / get_balance / get_evidence / get_ruling / get_dispute_opened_at anyone Read-only state.
psychology

AI consensus mechanism

The ruling runs through gl.eq_principle.prompt_comparative, GenLayer's equivalence-principle mechanism for consensus over language-based judgments.

The principle tells validators which field has to match exactly, payer_refund_percent, and which is allowed to vary in wording, reasoning, since no two models explain a decision in identical prose even when they agree on the outcome.

cancel_deal() — the real thing 
@gl.public.write
def cancel_deal(self) -> None:
    if gl.message.sender_address != self.payer:
        raise gl.vm.UserError("Only the payer can cancel")
    allowed = self.status in ("AwaitingFunding", "Funded") or (
        self.status == "Disputed" and not self.payee_evidence
    )
    if not allowed:
        raise gl.vm.UserError("Cannot cancel once the payee has submitted evidence")
    amount = self.balance
    self.status = "Cancelled"
    if amount > u256(0):
        _Recipient(self.payer).emit_transfer(value=amount)
