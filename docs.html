Technical reference

EvidenceEscrow is a single GenLayer Intelligent Contract, written in Python against the GenVM runtime. This page covers its public interface directly; for the reasoning behind the design, see how it works.

State machine

Every deal moves through a fixed sequence. The happy path skips the dispute stages entirely, and a cancelled deal can branch off early from either of the first two stages, or from a dispute the payee hasn't responded to yet:

AwaitingFunding --fund()--> Funded --confirm_complete()--> Released

Funded --submit_evidence()--> Disputed --resolve_dispute()--> Resolved

AwaitingFunding / Funded / Disputed (payee hasn't responded yet)
  --cancel_deal()--> Cancelled

Every transition is access-controlled: only the payer can call fund(), confirm_complete(), or cancel_deal(); only the payer or payee can call submit_evidence() or resolve_dispute(). Anyone else is rejected before any AI call happens. cancel_deal() has one extra rule: it stops working the moment the payee has submitted evidence, so it can never be used to make a live claim disappear.

Public interface

confirm_complete()payerReleases the full balance to the payee. No dispute, no AI.

Consensus

The ruling runs through gl.eq_principle.prompt_comparative, with a principle telling validators which field has to match exactly (payer_refund_percent) and which is allowed to vary in wording (reasoning), since no two models explain a decision in identical prose even when they agree on the outcome.
